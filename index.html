Privacy Policy for CloakWA

Effective Date: October 12, 2026 | Last Updated: October 2026

CloakWA ("the Extension") operates under a strict Zero-Remote-Data-Collection architecture in full compliance with the Google Chrome Web Store Developer Program Policies (including Limited Use), EU GDPR, and the Malaysian Personal Data Protection Act (PDPA).

1. Core Privacy Principle: 100% Local Chat Processing

CloakWA operates as a client-side optical privacy and workspace security utility directly inside your web browser.

  • Zero Remote Collection: We do not collect, transmit, store, or share your chat messages, media files, contact names, or phone numbers on any external server. All optical veil blurring processes data ephemerally inside your local browser memory.
  • Zero Telemetry & Analytics: We do not embed third-party analytics scripts (such as Google Analytics, Mixpanel, or Sentry), tracking pixels, or behavioral telemetry.

2. Data Stored Locally on Your Device

CloakWA uses standard browser storage APIs (chrome.storage.sync and chrome.storage.local) strictly on your device:

  • Privacy & UI Preferences (chrome.storage.sync): Stores your boolean toggle states (e.g., blur preferences, auto-lock timeout, zen mode).
  • Security PIN Hash (chrome.storage.sync): If you configure a 4-digit Auto-Lock PIN, it is hashed locally using PBKDF2-SHA256 (100,000 iterations) with a cryptographically random 16-byte per-device salt. Your plaintext PIN is never stored and never transmitted.
  • Workspace Contact Auditor (Local CSV Export): When manually triggered by the user, sidebar metadata is indexed into a standard CSV file directly in browser memory (Blob) and downloaded locally. Personal message previews are strictly excluded.

3. External Network Requests (License Verification Only)

CloakWA makes external HTTPS requests strictly and exclusively to Polar.sh (https://api.polar.sh/v1/customer-portal/license-keys/*) when you activate, periodically verify, or deactivate a CloakWA Pro license key.

  • Data Transmitted: Your entered License Key string (key), Organization ID (organization_id), extension version, and activation ID (activation_id).
  • No personal WhatsApp data is ever sent during licensing verification.

4. Chrome Web Store Limited Use Disclosure

CloakWA's use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements:

  • We only use host permissions (https://web.whatsapp.com/*) to apply local CSS privacy filters and inactivity shield overlays.
  • We do not transfer, sell, or use any user data for personalized advertising, creditworthiness, or data brokering.

6. User Rights & Data Erasure

You can view, modify, or permanently erase all extension data at any time by:

  • Deactivating your license in the CloakWA Options page, or
  • Uninstalling CloakWA from chrome://extensions/ (which immediately purges all local and synced extension storage).
